# 宜蘭太平山×平溪三日遊攻略（11/4–11/6）

👉 **網站：<https://sesame55.github.io/gogogo110406/>**

三天兩夜團體旅遊的行程網頁，主要給團員用手機查看：行前提醒、每天的行程、店家和景點推薦、小地圖、費用和準備清單都在同一個網址。

## 怎麼用

- **翻頁**：每天分早上／中午／下午／晚上四頁。用右下角的箭頭翻頁，手機上也可以左右滑動。
- **選單**：右上角三條線可以直接跳到任一天、任一時段；選單最下面能調整**字體大小**（小／中／大）。
- **深色模式**：右上角月亮按鈕切換，沒有手動切換時會跟著手機設定。
- **地圖**：店家和景點的小地圖都可以點標記看營業時間，名稱點下去會開 Google 地圖導航。
- **準備清單**：「行前必看」頁的清單可以打勾，會記在自己的手機上。

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 行程內容（改文字主要改這裡） |
| `style.css` | 樣式、配色（旅遊手帳風，含深色模式） |
| `app.js` | 翻頁、選單、字體大小、小地圖繪製 |
| `streets.js` | 小地圖的街道資料（由 `tools/` 自動產生，不要手動改） |
| `tools/` | 產生地圖資料和路線圖的工具，使用方式見 [tools/README.md](tools/README.md) |
